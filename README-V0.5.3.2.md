# Marinos AppBox Manager V0.5.3.2

Correctif d’interface Jellyfin :

- le libellé `Port Plex` devient `Port Jellyfin` sur une AppBox Jellyfin ;
- les cartes `Port Tautulli` et `Claim Plex` ne sont plus affichées pour Jellyfin ;
- le logo Jellyfin temporaire est remplacé par le visuel fourni ;
- le Command Center affiche `Jellyfin : <port>` au lieu de `Plex : <port>`.

Cette version ne modifie ni les AppBox, ni leurs ports, ni leurs données.
